# Action Macro Privacy Policy

Public privacy policy for the Action Macro Chrome extension, in Korean and English.

- [Read the privacy policy](https://zvz-dev.github.io/Action-Macro-Privacy-policy/)
- [Markdown source](privacy-policy.md)

## Files

- `index.html`: GitHub Pages entry point.
- `privacy-policy.html`: Standalone HTML copy of the policy.
- `privacy-policy.md`: Editable bilingual policy text.

The HTML page has no external scripts, fonts, analytics, or other external assets.

## Publishing

GitHub Pages should publish from the root of the `main` branch.

## 개인정보처리방침

Action Macro Chrome 확장 프로그램의 한국어·영어 개인정보처리방침입니다.
HTML 파일은 외부 스크립트·폰트·분석 도구를 사용하지 않습니다.
